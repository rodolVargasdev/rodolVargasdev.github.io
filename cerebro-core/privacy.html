Política de privacidad de Cerebro-Core

Vigente desde el 28 de octubre de 2026.

Quién la usa

Cerebro-Core es una herramienta privada. Solo la usa su dueño, Rodolfo Vargas, con sus propias cuentas de Google. No está disponible para el público.

Qué datos de Google lee

  • Gmail: mensajes y etiquetas, para clasificar el correo y aplicar etiquetas.
  • Google Drive: archivos, para buscarlos y leerlos, y los archivos que la propia herramienta crea.

Para qué los usa

Solo para dar al dueño resúmenes, clasificación de su correo y notas propias. Los datos no se venden, no se comparten con terceros, no se usan para publicidad y no se usan para entrenar modelos de inteligencia artificial de uso general.

Dónde se guardan

Los resultados se guardan en la infraestructura privada del dueño (su proyecto de Google Cloud y su repositorio privado de notas), con acceso restringido por autenticación.

Política de datos de usuario de las API de Google

El uso y la transferencia a cualquier otra aplicación de la información recibida de las API de Google se ajustan a la Política de datos de usuario de los servicios de las API de Google, incluidos los requisitos de uso limitado.

Cómo revocar el acceso

El acceso se retira en cualquier momento desde la página de permisos de la cuenta de Google.
